## Why this matters

> [!SCENARIO] Photos, texts and a car park
> Northline launches product reviews with photos. The React Native app posts each photo, often 6 MB straight off the camera, to the Node API, which holds it in memory and writes it to Blob storage. On the first sale weekend a few hundred uploads arrive at once, the API instances run out of memory and restart, and checkout slows with them.
>
> Two more requests land the same week. Marketing wants order emails from northline.com and "out for delivery" texts for customers in the UK and Bengaluru. The click-and-collect team wants a store finder, and staff to bring the parcel out when a customer pulls into one of the 14 store car parks.
>
> Ana owns the API, Leo owns the app, and Priya wants one plan.

## Uploads: hand the client a valet key

Ana's API is carrying bytes, and storage does that job better. In the **[valet key pattern](gl:valet-key-pattern)** the client asks the API for permission, gets back a narrow, short-lived key, and uploads to storage directly.

In Azure the key is a [shared access signature](gl:shared-access-signature), and the right kind is a **user delegation SAS**. The API's [managed identity](gl:managed-identity) gets a delegation key from Entra ID and signs with it, so no account key is involved. Each SAS grants create and write on **one blob name the API chooses**, such as `review-uploads/r-88213/3f9c.jpg`, over HTTPS, for 15 minutes. The ceiling is seven days; stay far below it.

This is what the contractor in [lesson 3.1](lesson:3.1) should have built instead of a signed URL in the app build. ==The client gets the key to one locker for fifteen minutes, never the master key to the building.==

A SAS cannot cap file size or prove the file is a JPEG, so the receiving [storage container](gl:storage-container) stays private and its contents count as hostile until checked. Browser uploads also need a [CORS](gl:cross-origin-resource-sharing) rule on the storage account; the native app doesn't.

**After the upload, nothing calls the API.**

1. **[Malware scanning](gl:malware-scanning)** in Defender for Storage, part of [Microsoft Defender for Cloud](gl:microsoft-defender-for-cloud), scans each new blob and writes the verdict to a blob index tag. It can soft-delete malicious files itself.
2. The verdict also goes to an [Event Grid](gl:azure-event-grid) topic. An [event subscription](gl:event-subscription) filtered to clean results triggers a resize function in [Azure Functions](gl:azure-functions).
3. The function strips EXIF location data, writes three sizes to `review-images` behind Front Door, and queues the review for moderation.

Starting from the verdict, not from `BlobCreated`, means the resizer never touches an unscanned file.

## Email and SMS: a retiring service, and rules that outlast it

Ana's first draft used **[Azure Communication Services](gl:azure-communication-services)** (ACS), Azure's SendGrid and Twilio. Then Dev found its retirement notice.

In September 2026 Microsoft announced that ACS email, SMS, chat, Rooms and directly bought phone numbers retire on **30 September 2028**; calling continues only alongside Teams. From **23 October 2026** new customers can't sign up for the retiring services. Microsoft points to Marketplace partners such as Infobip and Telesign. Northline has no ACS resource, so: ==don't start new work on a service with a published retirement date.== Email goes to a transactional email provider and texts to an SMS platform such as Twilio, Infobip or Vonage, behind one notifier so the vendor can change.

The slow part is the same with any provider:

- **[Email authentication](gl:email-authentication).** Send from `orders.northline.com` with SPF and DKIM records and a DMARC policy. Gmail and Outlook.com demand all three from anyone sending over 5,000 messages a day. New senders start on low limits, so plan a two-to-four-week warm-up.
- **[Alphanumeric sender ID](gl:alphanumeric-sender-id).** UK customers see `NORTHLINE` instead of a number. Unregistered IDs have been blocked to UK numbers since June 2024, so register early. Nobody can reply STOP to a name, so add an opt-out link.
- **India.** Commercial texts need the sender ID and every template registered on the DLT platform; ACS never sent there directly. Allow weeks.
- **Push first.** A push notification ([lesson 11.4](lesson:11.4)) costs almost nothing; every SMS segment is charged.

## Maps: a store finder and "you've arrived"

**[Azure Maps](gl:azure-maps)** is Azure's Google Maps Platform: tiles, search and **[geocoding](gl:geocoding)**, routing and traffic, as REST APIs and a Web SDK. It replaces Bing Maps for Enterprise, which ends in June 2028. Its one tier, Gen2, has free monthly transactions (5,000 searches, for example), then about $4.50 per 1,000 (approximate pay-as-you-go list price; varies by region).

The store finder stays nearly free if the 14 stores are geocoded **once** and kept in Azure SQL; only a customer's postcode reaches the geocoder. The Maps key never ships: browsers get an Azure Maps SAS token from the API, valid for at most 24 hours, whose rate cap also caps the bill.

Three things in older blog posts have gone: the native Android and iOS SDKs (March 2025; apps now use the Web SDK in a WebView), Creator indoor maps, and the geofencing API (both September 2025).

So the **[geofence](gl:geofence)** lives on the phone. When an order is ready, the app registers one OS geofence around the store (iOS allows 20 per app, Android 100). On entry it calls `POST /orders/{id}/arrived` with an [idempotency key](gl:idempotency-key), because the OS can fire twice. Background geofencing needs "always" location permission, so an "I'm here" button is the default and the geofence is opt-in.

## In practice

- **Storage.** `stnlreviews`, shared-key access off. A [lifecycle management policy](gl:lifecycle-management-policy) deletes originals in `review-uploads` after seven days.
- **Scanning.** Defender for Storage with a monthly cap, and a filter that skips `review-images`, which Northline made itself.
- **Events.** Every event subscription has a dead-letter container.

**What it costs.** Defender for Storage is about $10 per storage account a month plus $0.15 per GB scanned (approximate list prices; they vary by region). 2,000 photos a day at 3 MB is about 180 GB a month, roughly $27. Maps stays near the free allowance. SMS is the line that grows.

**What breaks.** A SAS expiring mid-upload on a slow train: fetch a fresh one, don't lengthen it. Past the scanning cap files go unscanned, so treat `Not scanned` as not clean. A location prompt on first launch gets refused; ask at collection.

## Map it to what you know

| You already know | On Azure |
|---|---|
| An S3 pre-signed URL | A user delegation SAS for one blob |
| A Firebase Storage trigger running `sharp` | An Event Grid subscription to a function |
| ClamAV in a sidecar | Defender for Storage malware scanning |
| SendGrid and Twilio | ACS, now retiring: keep a third-party provider |
| Google Maps Platform or Mapbox | Azure Maps |
| Geofencing in `expo-location` | Unchanged: it stays on the device |

## Guiding your team

> [!TEAM]
> In a design review, ask:
>
> 1. **Does any file pass through our API?** The API should sign keys, not carry bytes.
> 2. **What can the SAS do, for how long, and who signs it?** Anything looser than create-only, minutes and a managed identity repeats lesson 3.1.
> 3. **What stops an unscanned file being shown?** Processing should start from the scan verdict.
> 4. **What does the vendor's retirement page say, and how hard is a swap?** A notifier seam makes it configuration.
> 5. **Does this need background location, or would a button do?** Always-on location costs trust and battery.

## Key takeaways

- Valet key: the API issues a create-only user delegation SAS for one blob, lasting minutes, and the client uploads directly.
- Treat uploads as hostile: a private container, Defender malware scanning, and processing only on a clean verdict.
- ACS email and SMS take no new customers from 23 October 2026 and retire on 30 September 2028. Use a third-party provider behind one notifier.
- Deliverability is yours with any vendor: SPF, DKIM and DMARC; registered sender IDs in the UK; DLT templates in India.
- Azure Maps Gen2 does tiles, geocoding and routing; geocode fixed places once. Its geofencing API has gone, so geofences live on the phone.
